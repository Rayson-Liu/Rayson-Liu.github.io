Features

核心功能

专为音乐爱好者设计的丰富功能，覆盖播放、管理、个性化全场景

🎼

B站账号同步

支持登录 Bilibili 并获取收藏夹，收藏音乐一键同步进本地

🎧

高品质音频播放

优先拉取更高码率音频流，清晰饱满的音质带来沉浸式聆听体验

🔥

音频下载

支持音频下载与下载管理，可自定义音质，离线也能随时收听

🎚️

10 段均衡器

覆盖 31–16K Hz 全频段，±12dB 增益调节，内置流行、摇滚、爵士、古典、电子、人声、低音增强等 8 种预设

📊

频谱可视化

大屏播放页实时音频频谱，自适应主题色，支持激进度调节

🎤

智能歌词

支持歌词显示/隐藏、手动搜索、逐行微调与重置，自动匹配歌曲歌词

🧩

轻量界面

轻量现代的界面设计，毛玻璃视觉效果与流畅动画

💿

系统音频控件

适配系统自带音频控件，锁屏与媒体键可直接控制播放

🎨

6 套精美主题

粉色、紫色、蓝色、绿色、橙色，以及 Apple Music 风格主题，支持深色/浅色模式

📂

本地歌单管理

支持创建、导入、导出 JSON 歌单，批量删除歌曲，一键播放整个歌单

📀

本地音乐库

导入并管理你自己的音频文件，离线播放、失效检测、重新定位、云端封面匹配，优先读取同目录 .lrc 歌词

Guide

快速上手

简单几步，开启你的音乐之旅

1

搜索与播放

在搜索框输入关键词，回车或点击搜索按钮，点击音乐卡片直接播放

2

分P切换

视频包含多个分P时，点击右侧列表按钮查看并切换分P

3

歌单管理

侧边栏创建歌单，支持导入/导出 JSON，批量删除与一键播放整个歌单

4

下载功能

在音乐卡片或歌单中点击下载按钮，可在下载管理器查看进度与记录，设置中可调音质

5

本地音乐

「本地」页面导入文件或文件夹，支持筛选排序、失效检测、重新定位与封面匹配

6

界面定制

设置中可切换 6 种主题色与深色/浅色模式，与客户端完全一致

7

均衡器

设置页提供 10 段图式 EQ，拖动滑块调参后点击「应用」生效，配置自动保存

8

频谱可视化

设置页可开关「大屏播放页频谱可视化」并调整激进度

9

歌词

大屏播放页右上角显示/隐藏歌词，支持手动搜索、逐行微调偏移与重置

Get Started

源码运行与构建

支持 macOS、Windows、Linux 全平台运行

📦 克隆项目
git clone https://github.com/Rayson-Liu/pink-music-app.git
🔧 安装依赖
npm install
🚀 启动开发服务
npm run dev
🎵 启动 Electron 客户端
npm run electron:dev

构建打包

🍎 macOS
npm run electron:build
🪟 Windows
npm run electron:build -- --win

默认下载目录

🍎 macOS
~/Library/Application Support/Pink Music/downloads/
🪟 Windows
%APPDATA%\Pink Music\downloads\
🐧 Linux
~/.config/Pink Music/downloads/

🍎 macOS 提示"无法打开"怎么办？

如果系统提示无法验证开发者或已损坏，请在终端中执行：

sudo xattr -r -d com.apple.quarantine

（注意末尾有空格，输入后将应用拖入终端，按回车并输入密码即可）
