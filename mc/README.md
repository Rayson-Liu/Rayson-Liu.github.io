# OpusMC · 离线单机版

从 B站 Toy 作品《不用下载的网页版MC，几乎完全还原！》整理出的**纯本地单机项目**。
去掉了登录、账号、三连解锁 / 赞助式奖励、签到、公告、云存档、皮肤披风商城、AI 同伴、遥测上报、社交邀请与联机房间服务，打开即玩，全程不连任何外部服务器。

原始技术底座（自研 WebGL2 体素引擎、世界生成、红石、附魔、生物、命令系统、存档格式等）完整保留，游戏内容没有任何删减。

## 运行

需要 **Python 3**（或任意静态文件服务器）。**不要直接双击 `index.html` 用 `file://` 打开** —— Web Worker、纹理与存档都要求 HTTP 同源环境。

```bash
cd opusmc-offline
python3 serve.py            # 默认 8080 端口
# 或指定端口
python3 serve.py 9000
```

然后浏览器打开 `http://localhost:8080`。

也可以用其他服务器：

```bash
npx serve .        # Node
php -S localhost:8080
```

要求浏览器支持 **WebGL2**（Chrome / Edge / Firefox / Safari 较新版本），无 WebGL2 时会显示启动失败提示。

### 首次启动流程

`玩家类型选择 → 画质自动测试 → 帧率测试 → 设备类型 → 标题界面 → 单人游戏 → 创建新的世界`。
这些都是本地设置，不会再出现用户协议、登录、公告或签到。设置保存在浏览器本地，之后再打开会直达标题界面。

## 静态托管（GitHub Pages 等）

技术上**可以直接托管**：整个项目是纯静态资源（HTML + JS + 图片），无服务端、无构建步骤、无环境变量、无外部域名请求，也不依赖自定义 HTTP 响应头。已按 GitHub Pages 项目页的形式实测部署在子路径 `<host>/<repo>/` 下，Web Worker、IndexedDB、WebGL2、创建世界并进入游戏全部正常：**0 个 404、0 个跨域请求、0 个运行时错误**。

仓库根目录已放置空的 `.nojekyll`，让 GitHub Pages 跳过 Jekyll 构建。

### 部署步骤

1. 新建仓库，把本目录**全部文件**推到 `main` 根目录（不要把整个项目再套一层子文件夹）。
2. `Settings → Pages → Build and deployment → Source` 选 **Deploy from a branch**，分支 `main`、目录 `/ (root)`，保存。
3. 等约 1 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

### 部署注意点

- **所有资源引用都是相对路径**（`js/xxx.js`、`new Worker('js/chunk_worker.js')`、`importScripts('assets.js', ...)`、`fetch('sounds/sfx/...')`），因此用户页 / 项目页 / 任意子路径都能工作；只要保证 `index.html` 与 `js/` 的相对位置不变。
- 必须走 HTTP(S) 同源，GitHub Pages 的 HTTPS 满足；**不能**用 `file://` 打开。
- GitHub Pages 不发 COOP/COEP 头，`crossOriginIsolated` 为 `false`。代码只在 `perf.js` 里把它用于可选的内存采样，不依赖 `SharedArrayBuffer`，因此无需额外配置。
- 首次访问需下载约 **19 MB / 87 个文件**，最大单文件 4.1 MB，远低于 GitHub 的单文件 100 MB 限制。但 Pages 有每月 100 GB 软带宽限制且不应用作纯文件分发 / CDN，访问量较大时建议换 Cloudflare Pages、Netlify 或自建静态服务器。
- 存档按 origin 隔离在浏览器 IndexedDB，**换域名或换子路径等于换一份存档**，迁移前请先用游戏内「导出世界」备份。

> ⚠️ **法律提示（比技术问题更重要）**：把项目推到公开仓库并开启 Pages 属于**公开分发**，与本地个人学习性质完全不同。项目内含从原版 Minecraft 客户端导出的纹理、字体、方块 / 配方 / 结构数据、终末之诗，引擎代码著作权归原 UP 主所有。未经授权公开托管可能触发 DMCA 投诉，导致仓库被删除、Pages 下线甚至账号受限。若确需公开托管，请先取得 Mojang / Microsoft 与原作者授权，或把素材替换为完全原创 / 合规授权的版本。

## 目录结构

```
opusmc-offline/
├── index.html          本地入口（无外部依赖、无跳转）
├── favicon.ico         本地图标
├── serve.py            静态服务器
├── start.sh            一键启动
├── README.md
└── js/                 81 个 JS 文件 + 1 个图集
    ├── offline.js      离线接管层（新增）
    ├── assets.js       内嵌纹理 / 字体 / 界面素材
    ├── *_data.js       从原版导出的方块 / 物品 / 配方 / 实体 / 结构 / 世界生成数据
    ├── render*.js      WebGL2 渲染器、网格化、光影
    ├── worldgen*.js    世界生成（Worker 并行）
    ├── chunk_worker.js 区块生成 / 装饰 / 网格化 Worker（运行时动态加载）
    ├── gen_worker.js   地形生成 Worker（运行时动态加载）
    ├── sound_events.js 音效事件表（可选，默认不加载）
    ├── vstates_data.js 方块状态表（导出世界时按需加载）
    ├── emoji.webp      聊天表情图集
    ├── screens.js      UI 界面
    └── main.js         启动入口
```

`chunk_worker.js`、`gen_worker.js`、`vstates_data.js`、`emoji.webp` 不在页面的 `<script src>` 列表里，是原项目通过 `new Worker()`、动态注入 `<script>` 或 `importScripts()` 拉取的，已一并补齐。`sound_events.js` 为可选项，见「声音」一节。

存档写在浏览器 **IndexedDB**（`localStorage` 兜底），按「域名 + 端口」隔离。换端口或换浏览器等于换一份存档，请自行用「导出」功能备份。清理站点数据会清空存档。

## 声音

### 默认：程序化合成音（应该有声音）

`js/audio.js` 用 WebAudio 振荡器与噪声实时合成音效，**不依赖任何音频文件**：脚步、挖掘 / 破坏 / 放置、按钮点击、受伤、爆炸、TNT 引信、水花、进食、弓箭、开关门、升级、提示音、生物叫声等。正常游玩应该能听到这些声音。

> 修复记录：早期离线版因音效包缺失却被判定为「已播放」，连合成音也被吞掉，导致全程静音。现已让 `Sound.ev()` 在无音效包时正确返回 `false` 并回退到合成音，同时保留「显示字幕」功能。

### 不包含：原版录音 / 背景音乐 / 唱片

线上版带 4849 个 `sounds/sfx/*.m4a` 原版音效文件（约 20 MB+）；本离线包**未包含**它们，背景音乐与唱片也已被原作者移除（版权原因）。所以不会有原版音色的脚步声、环境音、BGM 与唱片音乐 —— 这部分「没有声音」是预期行为。

如需原版音效：自行准备 `sounds/sfx/` 目录（文件名见 `sound_events.js`），把 `index.html` 顶部的 `window.OPUSMC_SOUND_PACK` 改为 `true`。⚠️ 这些文件来自 Minecraft 客户端，公开分发有版权风险。

### 手机 / Termux 上没声音怎么排查

Termux 只是跑静态服务器（Python），声音由**手机浏览器**输出到系统音频，与 Termux 无关。按顺序检查：

1. **先点一下屏幕**。浏览器要求有用户手势才允许 `AudioContext` 出声；刚打开页面时音频上下文是挂起的，随便点一个菜单按钮即可解锁。
2. **调大媒体音量**。很多安卓机音量键默认调的是铃声音量，不是媒体音量。
3. **关掉静音开关 / 勿扰**。iPhone 的静音拨键会让网页静音；代码已尝试用 `audioSession` 与静音 `<audio>` 绕过，但系统级静音仍可能生效。
4. **切回前台再点一下**。页面进入后台会挂起音频省电，回来后点击一次唤醒。
5. **检查游戏内设置**：`选项 → 主音量` 别是 0%；打开「显示字幕」后，每次有声事件右下角会列出声音名，可用来区分「游戏没播」还是「手机没输出」。
6. **换浏览器**。部分 Termux 内置 WebView / 极简浏览器对 WebAudio 支持不全，建议 Chrome / Edge / Firefox 正式版。

## 已知限制

- **硬依赖 WebGL2**，无降级路径；软件渲染（如无头浏览器 SwiftShader）能跑但帧率很低。
- 首次加载约 19 MB JS 与 500+ 张内嵌贴图，弱网或低配设备需要等待。
- 音效为 WebAudio 程序化合成；原版录音音效、背景音乐与唱片音频未包含，详见「声音」一节。
- 移除了联机，因此「多人游戏」「房间」「公开房间」相关入口与能力不可用。
- 原项目中部分装饰开关（如披风 / 宠物显示）现在是无效果的空选项，保留仅为兼容存档中的设置字段。
